# QuizGenie – AI-Powered Quiz Generator

## About the Project
QuizGenie is an AI-powered quiz generation web application designed to help students prepare for exams more effectively. It uses Google's Gemini AI to transform lecture notes into multiple-choice questions (MCQs), making learning easier, faster, and more interactive.

## Key Features
- **AI Quiz Generation:** Generate MCQs automatically from pasted lecture notes using Gemini AI.
- **Custom Quiz Creation:** Choose a quiz title, subject, and number of questions.
- **Interactive Quizzes:** Attempt quizzes with four options for each question.
- **Instant Results:** View scores and identify correct and incorrect answers.
- **Quiz History:** Save and access previously generated quizzes.
- **Quiz Management:** View, rename, retake, and delete saved quizzes.
- **User Authentication:** Register and log in to access personal quizzes.

## Technologies Used
- Frontend: React.js and Vite
- Backend: Python and Flask
- Database: SQLite
- Generative AI: Google Gemini API
- Version Control: Git and GitHub

## Project Objective
The main objective of QuizGenie is to make exam preparation more convenient by using Generative AI to convert students' study materials into practice quizzes. It aims to improve students' understanding, revision, and self-assessment.
